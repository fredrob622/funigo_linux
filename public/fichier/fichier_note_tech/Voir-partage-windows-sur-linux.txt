Installation
------------

sudo apt update && sudo apt install cifs-utils -y

fred@sashimi:~/partage_ulysse/docker$ dpkg -l | grep cifs-utils.
ii  cifs-utils   2:7.4-1ubuntu0.26.04.3     amd64   Common Internet File System utilities

net user partage Partage_2010


On créé un fichier credentials_windows
--------------------------------------

sudo cat /etc/samba/credentials_windows
username=partage
password=Partage_2010




fred@sashimi:~/partage_ulysse/docker$ sudo chmod 600 /etc/samba/credentials_windows


fred@sashimi:~/partage_ulysse/docker$ ls -ltr  /etc/samba/credentials_windows
-rw------- 1 root root 37 Sep  8 15:08 /etc/samba/credentials_windows


On créer le répertoire de montage
---------------------------------

mkdir -p /home/fred/partage_ulysse/docker
