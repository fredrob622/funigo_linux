##############################################################################################################################################################################
commande de configuration du IP fixe sur WIFI
##############################################################################################################################################################################

sudo nmcli connection modify "netplan-wlan0-Freebox-128B17" \
  ipv4.method manual \
  ipv4.addresses 192.168.1.10/24 \
  ipv4.gateway 192.168.1.254 \
  ipv4.dns "192.168.1.254 8.8.8.8"

##############################################################################################################################################################################
vérifier Netplan
##############################################################################################################################################################################

Netplan est un outil de configuration réseau développé par Canonical (créateurs d’Ubuntu) pour simplifier la gestion des interfaces réseau sous Linux. 
Il remplace les anciens outils comme /etc/network/interfaces (Debian) ou NetworkManager (pour les connexions dynamiques).

Les configurations sont écrites en YAML (un format lisible par les humains).

 Ces fichiers décrivent la configuration réseau de ton Raspberry Pi.

fred@sashimi:~ $ ls -ltr /etc/netplan/
total 8
-rw------- 1 root root 275 Aug 19 10:13 90-NM-75a1216a-9d1a-30cd-8aca-ace5526ec021.yaml
-rw------- 1 root root 778 Aug 19 10:13 90-NM-adee2f9e-b621-3712-a116-cbda491de5d4.yaml

##############################################################################################################################################################################
appliquer les lodifs netplan
##############################################################################################################################################################################

sudo netplan apply
